# Hisaab React Native UI

Premium personal-finance mobile UI built with Expo, React Native and TypeScript.

## Run

```bash
npm install
npm start
```

Scan the QR code with Expo Go, or press `a` for Android / `i` for iOS.

## Included

- Sign in, sign up, forgot password, OTP and password reset UI
- Home dashboard
- Finance feature hub
- Add transaction flow
- Transactions list and filters
- Profile, Manage Subscription and Settings
- Reusable finance detail screen for all finance tools
- Local demo data and working in-app navigation

This project is UI-first. Replace the local demo actions with your API/service layer when the backend is ready.
