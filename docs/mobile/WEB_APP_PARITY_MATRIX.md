## Reachability finding

The primary tab bar currently exposes Home, Finance, Split Money, Transactions, and Profile. Finance is the practical “More” surface, but it is not labeled or structured as one. Transaction creation is reachable from Home quick actions through the parent transaction-create stack. Home notifications open the dedicated Recurring stack. The AI Coach tile is the remaining Finance item that still lands on the generic feature screen, because it has no audited API.

2026-10-08 Android emulator (`NovaPlay_API35`, Android 15) plus local web at `http://localhost:3000` and gateway at `http://localhost:8787`:

- Android login, SecureStore restore after force-stop, logout, Finance open, and system back to Home passed.
- Home figures matched the dashboard API: income ₹510.00, expenses ₹125.50, net ₹384.50. No NaN or Infinity.
- Transaction create from the Android UI, web visibility, web create visible on Android, and the CSV share sheet passed.
- Closure pass on the same emulator opened Split, Categories, Budgets, Goals, Bills, Borrow/Lend, Loans, Cards, UPI, Investments, IPO, Analytics, and Accounts. Home still showed income ₹587.00, expenses ₹125.50, net ₹461.50, and no NaN.
- Split create no longer crashes on an empty amount. Person detail shows the nested name and balances. Analytics uses ISO datetimes and matches the dashboard.
- Post-fix web UI recheck did not complete because `/login` stopped responding. API still has `QAUIEqual`, `QA Emergency`, currency INR, and timezone Asia/Kolkata.
- Offline transaction save showed `Could not save` / `Network request failed` and did not report success.
- Native image, camera, and document pickers were exercised on 2026-10-09 through split receipts and transaction attachments. See `FINAL_REMAINING_CLOSURE.md`.
- iOS was not tested.
